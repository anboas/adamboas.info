The current AI adoption conversation is still too small. It treats AI mostly as a productivity layer: a person drafts faster, summarizes faster, searches faster, codes faster, or prepares a briefing faster. That matters, but it is not the strategic shift.

The strategic shift begins when agents stop being personal productivity aids and start becoming assigned work capacity inside organizations. When an agent has a role, credentials, tools, memory, approval paths, and the ability to operate across systems, the organization has created a non-person work entity. It is not an employee. It is not an ordinary tool. It is governed digital work capacity.

That is why agent workforce integration needs its own framework.

The Agent Workforce Integration argument is the organizational counterpart to ACP-RA. ACP-RA defines the primitives for governed autonomy: Non-Person Entity identity, Persona, Trust Scope Manifest, Work Unit, Action Envelope, Evidence Ledger, Model Assurance Profile, policy bundle, and delegation chain. Workforce integration translates those primitives into operating rules for leaders: who owns the agent, what work may be assigned, what authority is granted, what evidence is retained, when human approval is required, how performance is measured, and when the agent is retired.

The force-creation claim matters. AI tools make existing workers more efficient. Governed agents create additional capacity that can be assigned, measured, supervised, constrained, improved, and retired. That is a workforce planning issue, not just an IT adoption issue.

The strongest early edge is Department of War staff work: policy comparison, cyber evidence packages, continuous ATO support, acquisition package review, requirements traceability, digital engineering evidence, vulnerability closure, and mission support coordination. These are evidence-heavy, reversible, reviewable domains where the bottleneck is often staffed execution rather than insight.

CAF-RA is part of the same story. ACP mediates authority; CAF verifies behavior. Agent work should leave replayable evidence through Action Envelopes, Evidence Ledgers, approvals, exceptions, outputs, and retirement decisions. Otherwise an organization can deploy agents without being able to explain what they did.

The minimum standard should be blunt: no production agent receives a Work Unit unless it has a registered NPE identity, persona, accountable owner, signed Trust Scope Manifest, policy bundle, MAP allowlist, Action Envelope logging, Evidence Ledger anchoring, records disposition, and retirement path.

The measurement standard should be equally concrete: agent-hours/day, autonomous task closure rate, human approval rate per mission thread, compute-to-output elasticity, Action Envelope coverage, Evidence Ledger completeness, trust-scope violation rate, escalation precision, revocation time, rollback success, and supervisor load. Counting deployed agents is not enough. The test is whether governed agents create usable capacity.

The workforce legitimacy standard also has to be explicit. Agentic rollout will fail inside real organizations if it becomes opaque surveillance, hidden displacement, or a quiet ratchet on output expectations. The better path is skill pathways into agent supervision, transparent use of agent outputs, worker impact review, preservation of human judgment, and measurement of whether agents reduce low-value burden rather than merely accelerating leadership products.

The practical action agenda is straightforward:

- First 30 days: define agent categories, name executive sponsors, inventory existing agentic workflows, and pause unmanaged high-risk expansion.
- First 60 days: create the draft policy, registry schema, risk-tier model, Trust Scope Manifest requirement, Action Envelope/Evidence Ledger standard, and contract clause set.
- First 90 days: run bounded pilots in reviewable staff workflows such as policy comparison, cyber evidence review, acquisition package completeness, continuous ATO support, and knowledge retrieval.
- First 180 days: integrate agent NPE identity with IAM, records rules, procurement language, supervisor training, Work Unit review, and mission metrics.
- First year: account for agent-hours, Work Unit closure, human approval rates, supervisor load, and agent supervisor roles in workforce planning.

This does not require pretending agents are employees. It requires refusing to treat assigned agentic work as ordinary software use. Agents entering the workforce need identity, authority boundaries, evidence, supervision, metrics, and accountability.

The alternative is a shadow workforce. The better answer is a governed one.
